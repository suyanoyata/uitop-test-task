# uitop-test-task

## How to run

Install dependencies using your preferred package manager

`bun install` / `npm install` / `pnpm install`

Create database models using 

`bun db:push` at root folder

Run backend and frontend using `bun dev` at root folder

## Building and running

To build a web package run `bun web:build` at root folder, then run `bun run prod` to run a production build of NextJS package and API.
